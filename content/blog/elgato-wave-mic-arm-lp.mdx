## Elgato Wave Mic Arm LP とは？

結論から言うと、**モニターの下をくぐらせて使う、背の低い（Low Profile）マイクアーム**です。

一般的なマイクアームは、上に高く伸びて、上からマイクを吊るす形が多いですよね。Wave Mic Arm LP はその逆です。デスクの天板にクランプで固定し、**水平方向にスッと伸びる**作りになっています。

![手に持った Elgato Wave Mic Arm LP の全体像。クランプ部分に Elgato のロゴがあり、2本のアームが水平に折りたたまれている](/images/elgato-wave-mic-arm-lp/arm-overview.jpg)

ざっくり特徴をまとめると、こんな感じです。

- 背が低く、視界やカメラの画角にアームが入りにくい
- デスクの天板にクランプで固定するタイプ
- アームの内側にケーブルを収納できる
- ケーブルを隠すカバーはマグネット式
- 関節の角度をノブで調整できる

僕は Amazon.co.jp 限定モデル（型番 10AAN9901-AMZ）を購入しました。

## 実際に使ってよかったところ

### しょぼいアームから替えたら、素直に感動した

いちばん伝えたいのはこれです。以前のアームから替えただけで、デスクに座るたびの小さなストレスが消えました。

手に持った瞬間から、作りのしっかり感が違います。金属のマットな質感で、関節もカチッと決まる。毎日触る道具だからこそ、この差は大きいと感じました。

「マイクアームなんて、マイクを支えられればいい」と思っていた過去の自分に、教えてあげたいくらいです。

### ケーブルをアーム内部に隠せる。しかも蓋がマグネットでパチッと決まる

見た目がすっきりする最大の理由がこれです。アームの内側が溝になっていて、マイクのケーブルを中に収められます。

![Elgato Wave Mic Arm LP のアーム内側。溝の中にマイクケーブルが収まり、両端にカバー固定用のマグネットが見える](/images/elgato-wave-mic-arm-lp/cable-channel.jpg)

写真の銀色の四角い部分がマグネットです。ケーブルを入れたらカバーを近づけるだけで、**パチッ**と吸い付いて閉まります。この感触が地味に気持ちいい。

ケーブルがブラブラしないので、デスク上がかなり整って見えます。余ったケーブルも、束ねて中に押し込んでしまえば見えません。

### アームが水平に伸びるので、モニターと干渉しにくい

上に高く伸びるアームだと、モニターの前にアームが被さったり、画面の一部が隠れたりしがちです。Wave Mic Arm LP はモニターの下を**水平に**スッと伸びてくるので、その心配がほとんどありません。

僕はモニターアームと併用していますが、アーム同士がぶつかることもなく使えています。画面の視界がすっきりしたままなのは、想像以上に快適でした。

### 出したり、しまったりが一瞬

使うときは手前に引き出し、使わないときはモニター下へ押し戻すだけ。これが本当に一瞬です。

![Elgato Wave Mic Arm LP を手前に引き出し、キーボードの上にマイクを構えた状態](/images/elgato-wave-mic-arm-lp/mic-in-use.jpg)

![Elgato Wave Mic Arm LP をモニター横へしまった状態。キーボード周りの作業スペースが広く空いている](/images/elgato-wave-mic-arm-lp/desk-stowed.jpg)

しまえばキーボード周りが広く空くので、普段の作業の邪魔になりません。会議や録音のときだけサッと出せばいい。この気軽さのおかげで、マイクを使うハードルがぐっと下がりました。

## 逆に「うーん」と思ったところ

正直に書くと、気になる点もあります。

- **設置位置はけっこう考える必要がある**: 水平方向に動く前提なので、クランプをどこに付けるかで使い勝手が大きく変わります。最初の位置決めは少し試行錯誤しました。
- **ケーブルの収納はひと手間**: 内部に隠すぶん、最初にケーブルを通す作業は少し面倒です。ただ、一度やってしまえば終わりなので、気になるのは最初だけでした。

## ネットの口コミ・評判は本当？ 実際に使って答え合わせ

購入前に口コミもいろいろ読みました。Elgato Wave Mic Arm LP でよく見かける評判について、実際に使った立場で答え合わせしてみます。

- **「見た目がすっきりする」→ 本当**。ケーブルをアーム内に隠せるので、デスク上がかなり整います。マグネットのカバーもパチッと決まって気持ちいいです。
- **「視界や画角の邪魔になりにくい」→ 本当**。背が低いので、上からアームが垂れてくる感じがありません。画面を見るときの視界もすっきりしています。
- **「作りがしっかりしている」→ 本当**。以前使っていたアームとは段違いでした。金属の質感も含めて、所有感があります。
- **「モニターの邪魔にならない」→ 本当**。水平に伸びるので、画面の前にアームが被さりません。モニターアームと併用しても干渉せずに使えています。
- **「値段が高い」→ 半分本当**。安いアームと比べれば高いです。ただ、毎日使うものの小さなストレスが消えたことを考えると、僕は納得しています。

総じて、**良い評判はほぼ本当、気になる評判は「値段」くらい**という印象です。毎日使うものと割り切れるかどうかが、満足度の分かれ目だと思います。

## よくある疑問（FAQ）

**Q. モニターアームと一緒に使える？**
使えます。僕はモニターアームと併用していますが、マイクアームがモニターの下を水平に伸びるので、干渉せずに使えています。念のため、モニターの下にアームが通る空間があるかは事前に見ておくと安心です。

**Q. どんなマイクが付けられる？**
僕は marantz Professional のコンデンサーマイクを、ショックマウントごと付けて使っています。対応するネジ規格や耐荷重は、購入前に公式・販売ページで確認してください。

**Q. デスクへの設置は難しい？**
天板にクランプで挟んで固定するタイプです。作業自体は難しくありませんでした。ただし天板の厚さや、天板の奥に固定できるスペースがあるかで向き不向きが出るので、対応する天板の厚さは販売ページで確認してください。

**Q. ケーブルは全部隠せる？**
アーム部分のケーブルは、内側の溝にほぼ収まりました。余った分は束ねて中に入れています。マイク側とPC側の端っこは、当然ですが外に出ます。

**Q. 普段は邪魔にならない？**
使わないときはモニター下に押し戻せば、キーボード周りは広く空きます。出し入れが一瞬なので、使うときだけ出す運用がラクです。
