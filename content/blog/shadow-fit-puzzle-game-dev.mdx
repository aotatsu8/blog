新しいブラウザゲームを作りました。**Shadow Fit** といいます。

インストールもアカウント登録も要りません。開いた瞬間に1問目が始まります。

## どんなゲームか

**ブロックの塊を回して、壁に映る影を型穴にぴったり合わせるパズル**です。

- 画面右の立体を**ドラッグして回す**。操作はこれだけ
- 左の壁に影が映るので、型穴に重なる角度を探す
- 影が型穴と**90%以上重なった状態を保つ**とクリア
- 1問ごとに持ち時間があり、時間切れで挑戦終了
- 記録は**続けて合わせた数**。形は30種類

コツは「だいたい合っている」で手を止めないことです。一致率は角度ではなく**影そのものの重なり率**で測っているので、あと一歩の角度を詰める必要があります。

PCはマウス、スマホは指でドラッグ。ただし**横画面専用**です。

## 「影合わせ」を選んだ理由

ブラウザゲームのパズル枠は、match-3・merge・water sort・落ちものでほぼ埋まっています。**同じ型の作品を足しても、遊んでもらう理由がありません。**

そこで「まだ並んでいないもの」を探したら、影合わせがほとんど無いことに気づきました。近いのは iOS 有料アプリの Shadowmatic くらい。ここに決めました。

作りは TypeScript + Phaser 3。**画像も音声もファイルを持っていません**。形は立方体の集まりで、音はその場で合成しています。BGMは残り時間が減るほど速く厚くなるので、**曲そのものがカウントダウン**になっています。

## AIに任せられなかったこと

実装の大半は Claude Code と進めました。3D回転まわりの厄介なバグは、正直ひとりなら詰んでいたと思います。

ただ、一つだけ差し戻したものがあります。**「惜しい角度で指を離したら正解に吸い付く」という救済機能**です。動作は完璧でした。それでも消しました。**簡単になりすぎたから**です。

AIは頼んだ機能を正確に作ります。でも、それが面白さを壊すかどうかは判断しません。**そこを決めるのは最後まで自分の仕事**でした。

## まとめ

- 影を型穴に合わせるだけの、**ルールが1行で済むパズル**
- 操作はドラッグのみ。説明画面なし、**開いてすぐ遊べる**
- 一致率は重なりで判定。**「惜しい」は通らない**のが気持ちいいところ
