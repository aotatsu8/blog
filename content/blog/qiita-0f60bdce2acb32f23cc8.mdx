会社のPC（JIS配列設定）に自前のUSキーボードを接続した際、印字と入力結果がズレて混乱しやすいキーの対応表です。

## 1. 最もズレやすい記号・キーの対応表

| JIS配列で打ちたい文字 | USキーボードで押す位置 | USキーの印字 |
| :--- | :--- | :--- |
| **`**（バッククォート） | 左上（Escの下） | **` ~** |
| **+**（プラス） | **Shift** + **;** | **; :** |
| **:**（コロン） | **'** の位置 | **' "** |
| **"**（ダブルクォート） | **Shift** + **2** | **2 @** |
| **'**（シングルクォート） | **Shift** + **7** | **7 &** |
| **(**（左カッコ） | **Shift** + **8** | **8 *** |
| **)**（右カッコ） | **Shift** + **9** | **9 (** |
| **~**（チルダ） | **Shift** + **^** の位置（**=** の横） | **= +** |
| **=**（イコール） | **Shift** + **-** | **- _** |
| **@**（アットマーク） | **[** の位置 | **[ \{** |
| **[**（左角カッコ） | **]** の位置 | **] \}** |
| **]**（右角カッコ） | **\** の位置 | **\ |** |

## 2. ズレが発生する主なポイント

- **Enterキー周辺（右側記号エリア）**  
  USキーボードの `[` `]` `\` を押すと、JIS設定ではそれぞれ `@` `[` `]` にズレます。
- **数字キーのShift入力**  
  JIS設定の挙動になるため、USキーボードに印字された記号（`@` や `"` など）とは異なる記号が入力されます。
- **長音記号（ー）**  
  USキーボードにはJISの「ろ（`\`）」キーがないため、長音記号を入力する場合は右上（Backspaceの左隣）の **`=` キー** を押します。

## 3. （参考）PC側のキーボード設定をUS配列に変更する方法

もしOSの設定変更が許可されている場合は、配列設定を「US（英語）」に変更すると印字通りの入力が可能になります。

### Windows 11 の場合
1. **設定** > **時刻と言語** > **言語と地域** を開く
2. **日本語** の右にある `...` > **言語のオプション** を選択
3. キーボードレイアウトを **接続済みキーボードのレイアウトを使用する** または **英語キーボード (101/102キー)** に変更
4. PCを再起動する

### macOS の場合
1. **システム設定** > **キーボード** を開く
2. **入力ソース** の「編集」を選択
3. キーボードの種類を **ANSI (標準)** に変更
